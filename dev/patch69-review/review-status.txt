Patch 69 review completed - 2026-11-10

Scope and decisions verified
- Current mappings and workbook parser profiles are edited directly. No mapping-set
  draft/publish/retire workflow remains in the application.
- One immutable configuration snapshot is stored per import operation. Results
  link directly to the run that inserted them; separate uploads can add results
  to an explicitly selected existing sample without changing sample metadata.
- Original workbook bytes remain in files.documents; sample_documents supplies
  the sample links. import_runs stores source_document_id and has no duplicated
  source-file name, size, hash or SHA256 fields.
- Legacy mapping-set and import_run_rows tables are removed. Existing audit
  events remain, published scope overrides migrate, unpublished drafts are
  discarded, and unambiguous old result/run links are retained. Older runs may
  have no captured configuration or workbook; the provenance UI says so.
- Snapshot/source identity, original result/run links, archived file content and
  finalized run outcomes are protected by database guards. Run snapshot reads
  follow source-document visibility; documentless runs are creator/admin only.

Visibility and document behavior
- Uploaded source files and attachments use group names common to every linked
  sample. public_reader is unrestricted. Empty common groups reject the upload
  or coordinated edit atomically with an actionable message.
- The complete source workbook, including omitted source samples, constrains
  initial sharing for a partial upload. Later automatic synchronization retains
  that limit; users can explicitly review and change sharing in Documents.
- Single and bulk sample visibility edits ask Yes / No / Cancel. Yes is the
  primary/recommended choice; No preserves document sharing; Cancel saves nothing.
- Actual browser saves exercised all three choices in both modes. Database
  comparisons confirmed their effects and unchanged collection metadata,
  sub-location, timestamps, source identifiers and other non-sharing fields.
- Identical binary uploads reuse the document. Shared-document synchronization
  considers every linked sample; two-document independence and public_reader
  isolation are covered by live database tests.
- Unchanged document associations now retain their roles, notes and audit fields.
